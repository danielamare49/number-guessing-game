# Number Guessing Game

A simple Python game where the player tries to guess a randomly generated number between 1 and 100.

## How It Works

* Python randomly chooses a number between 1 and 100.
* The player enters guesses.
* The game tells the player if the guess is too high or too low.
* The game counts the number of attempts.
* The game ends when the correct number is guessed.

## How to Run

Make sure Python is installed, then run:

```bash
python guessing_game.py
```

## Example

```text
Guess the number: 50
Too low!

Guess the number: 75
Too high!

Guess the number: 63
Correct! You got it in 3 attempts.
```
